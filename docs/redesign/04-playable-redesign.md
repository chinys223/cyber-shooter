# 可玩版本重整紀錄

日期：2026-09-16

## 本輪目標

使用者回饋 Gemini 版本「單調、不夠生動」，操作、畫面與獎勵都不足。原始 P0 設計與實作把體驗縮到六次相近的點擊，雖有流程，卻缺少值得反覆操作的變化。本輪直接修改遊戲，而非再停留於提案。

本文件描述目前實作，優先於 01、02 文件中尚未實作的三關規格與六格小島提案。保留原作科幻、霓虹與雷射辨識元素，玩法則增加節奏與回饋。

### 星區內容

1. 星光出發站：9 顆目標，同時最多 3 顆，學會點擊、滑動與連擊。
2. 彩虹連鎖帶：12 顆目標，同時最多 4 顆，選擇連鎖目標提高效率。
3. 蹦蹦流星雨：15 顆目標，同時最多 5 顆，混合雙層泡泡與較大的移動範圍。
4. 烏雲船長：每輪三顆衛星與一次鼻子命中，共三輪。大招可以清衛星，但不會同時跳過剛露出的鼻子。

不設強制倒數或扣命。挑戰來自接續連擊、辨認泡泡種類與完成頭目階段。每完成一個星區即取得固定收藏，未完成當局不保存。

## 程式結構

- `src/game.js`：純玩法邏輯、目標生成、連擊、連鎖、充能、關卡轉換與頭目。
- `src/store.js`：UI 畫面、當局事件、本機收藏、設定與舊存檔兼容。
- `src/GameComponents.jsx`：角色、泡泡、太空背景、雷射、粒子、頭目與小島。
- `src/UI.jsx`、`src/index.css`：首頁、HUD、暫停、結算、小島與響應布局。
- `src/audio.js`：BGM 狀態與合成音效，播放失敗不阻斷遊戲。
- `src/game.test.js`：七項有狀態玩法測試。
- `scripts/browser-smoke.mjs`：實際滑鼠／觸控事件走完整流程。

原始 `Player.jsx`、`Level.jsx` 保留在專案中，主流程不掛載。沒有新增產品相依套件，沒有改動 Git 歷史，也沒有刪除原照片和音訊素材。修改前的 Gemini 版本另留存於本機暫存備份。

## 驗證與限制

已執行七項 Node 玩法測試，涵蓋重複命中、48 次救援完整流程、雙層泡泡、連鎖範圍、大招、轉場與連擊衰減。

瀏覽器流程以 Chrome headless、桌面 1440×900、直向 390×844 驗證：實際點擊通關、施放大招、暫停時間凍結、四項收藏、擺放與重新載入保存。觸控使用瀏覽器 touch 事件，驗證點擊及一次滑過兩個目標，並检查未處理例外與橫向溢出。

`npm run build` 成功；`npm run lint` 無錯誤，仍有原始未掛載 `Player.jsx` 與 `Level.jsx` 的四項警告。建置仍提示主包大於 500kB，尚未做完整效能優化。

這些檢查證明流程與互動可運作，不代表已證明兒童喜歡，也不等於真實手機效能測試。尚需在實際 Android／iOS 裝置和孩子試玩中驗證節奏、難度與持續興趣。
