提案名稱：星光救援隊：霓虹泡泡樂園  
核心需求：改善遊戲，讓小朋友容易玩懂、享受互動，並願意自主再玩。

## 閱讀順序

**目前已有可玩改版。請先閱讀 [可玩版本重整紀錄](./04-playable-redesign.md)。下列文件為原始規劃，部分關卡與小島規格已由實作迭代取代。**

1. [遊戲設計企劃](./01-game-design.md)：現況、定位、玩法、角色、關卡、視覺與介面。
2. [開發落地計畫](./02-development-plan.md)：現有程式如何調整、交付階段與驗收條件。
3. [兒童試玩與驗證計畫](./03-playtest-plan.md)：怎麼判斷「真的好玩」、觀察表與修改決策。

## 提案摘要

依使用者選擇「保留主題，重整玩法與視覺」，保留現有科幻、霓虹、雷射與太空場景元素。將現在「第一人稱移動、瞄準、擊破 15 個照片方塊」重整為「固定視角、點擊發射雷射泡泡棒、救出有個性的太空小怪獸、裝飾太空小島」。保留 3D 即時互動和命中回饋，降低第一次操作的負擔，增加有意義的選擇與可展示的成果。

先做一段 60–90 秒的試玩關卡。孩子能自行上手、喜歡救援反應、主動想再試，才擴充成三關、三隻怪獸與小島裝飾。

本次只新增規劃文件，尚未實作新玩法。現況結論來自原始碼閱讀，未執行遊戲或完成兒童試玩。年齡暫以 6–9 歲為設計假設；數值、時程與通過門檻均為提案，需透過實機與試玩修正。
